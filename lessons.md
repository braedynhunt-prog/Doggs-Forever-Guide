# Lessons (WoW Forever Atlas)

Format: one or two lines per entry - what went wrong, why, the rule going forward. Merge duplicates.

- 29 Oct 2026: a plan predicted the Wowhead XP data would check as fresh without comparing its pull dates (17-18 Oct) to the latest client build (28 Oct). Rule: check the actual dates before stating an expected result in a plan.
- 29 Oct 2026: Wowhead XP was called "browser-only" after testing only Wowhead's own endpoints; third-party mirrors (PandaQuest's Wowhead overrides and MCP server) were never searched. Rule: before declaring a source unreachable or manual, search GitHub and Reddit for mirrors and APIs.
- 29 Oct 2026: a subagent brief said to reuse score_items.py's weights without checking docs/forever-enh-stat-weights.md, which marks the mace term obsolete since 17 Oct. Rule: check the current doc before telling an agent to reuse constants from code.
- 1 Nov 2026: the 29 Oct loot report said two dungeons had "no creatures" and bosses' drops were "invisible" when only the zone-spawn field was empty; the NPC rows and drops were in the DB. Rule: when one DB field is empty, check the other tables keyed on the same id before declaring data absent.
- 1 Nov 2026: the 29 Oct plan said the guide "names no head item", taken from a report column produced by a text matcher (Gear:/Loot: lines only). Rule: grep the chapter before stating a gap derived from a matcher.
- 1 Nov 2026: three browser-pulled zone TSVs were piped into ingest_zone_tsv.py with cat; the first had no trailing newline, so the second zone's header landed mid-line and 62 Redridge quests were merged into Westfall (caught by the diff, restored from git). Rule: ingest one block per run, or add a newline between files, and diff row counts per zone before committing.
- 1 Nov 2026: reported "Forever campfires grant rested XP" from one Wowhead news line; the source is the Leatherworking Camp Tent, which the guide's own camping notes already say. Rule: grep the guide and docs for a mechanic before calling it new.
- 1 Nov 2026: a quest-reward scan used only QuestieDB's item questRewards field, which is incomplete for Forever items (the Spidersilk Sack had no quest link). Rule: scan rewards from the Wowhead zone JSON itemchoices/itemrewards fields, and use QuestieDB only as a cross-check.
- 1 Nov 2026: a chapter brief told the agent to pick up The Reports (291) in Kharanos without checking its prerequisites; the qdb row needs 287 and 98323 first, so the agent had to drop it. Rule: before a quest goes into a brief or overlay spec, read its preQuestGroup/preQuestSingle (quest row [11]/[12]) and its start NPC's spawn.
- 1 Nov 2026: the Phase 2 prep table flagged two Horde Zephras quests as usable because it checked only the race and class masks, not the Wowhead "side" field, and 2^33 (the Horde Skyborne bit) is not 2^32. Rule: a faction filter on Wowhead quest rows uses side (1 Alliance, 2 Horde, 3 both) first, and the race mask bit for Skyborne is 2^32 Alliance / 2^33 Horde.
- 1 Nov 2026: the overlay anchor set (quest/NPC/coordinate/title tokens) could not reach untagged [OC] notes, so all three Phase 3 agents stalled on ~100 lines until a literal-text anchor was added. Rule: when designing an edit language over a text file, include a plain-text anchor from the start and test it on the lines the report flags, not only on tagged steps.
- 1 Nov 2026: the warrior check_guide baseline came out empty twice because the grep pattern was typed from memory ("optional step without") instead of copied from the existing baseline ("optional quest step without"). Rule: when filtering tool output for a baseline, copy the match text from the existing baseline file, and check the line count before using it.
- 1 Nov 2026: the warrior build record said the Muren Stormpike chain was dropped for a "race mask without Skyborne", but the DB mask carries the Skyborne bit; the reason was never checked against the field. Rule: when a build record gives a data reason for dropping a quest, quote the field value next to it.
- 1 Nov 2026: a chapter line said the Forever DB had no Dead-tooth Jack NPC; it does (6093, "Dead-Tooth Jack") and the name search was case-sensitive. Rule: search DB names case-insensitively before declaring an entity absent.
- 1 Nov 2026: Feathers for Binding was proposed as optional without reading the quests that list it as a prerequisite (it gates 3,155 XP of the Nightfang Den chain; check_guide caught it after the edit). Rule: before proposing a quest as optional or dropped, list every quest whose preQuestGroup/preQuestSingle names it.
- 1 Nov 2026: the README told players to install into `_classic_era_`; the Forever client has its own `_forever_` folder (the beta used `_classic_beta_`). Rule: Forever addons and guides go in `World of Warcraft\_forever_\Interface\AddOns\`; the Era folder is a different client.
- 1 Nov 2026: four quoted-XP "fixes" were proposed from a regex matcher that credited every number on a line to the [QA] quest; three numbers belonged to the [QT] quests or to untagged chain quests and were right, and the fourth fix omitted a quest the chapter does (caught by the subagent before editing). Rule: before proposing a quoted-XP change, attribute each number to a specific quest id on the line (QT first, then QA, then the chain the chapter actually completes) and show that attribution in the proposal.
- 2 Nov 2026: the druid plan called Feral Charge and Primal Bite "trained at 20 / 25" from a SkillLineAbility + SpellLevels join; both are talents (Blizzard deep dive, Wowhead tooltips) and SpellLevels lists a level for talent spells too. Rule: a learn level from SpellLevels says nothing about how a spell is learned; check the acquire method / trainer list before calling a spell trained.
- 2 Nov 2026: the Phase 2 druid brief told three agents the bear band order was Str > Agi > Sta, typed from memory; the feral weights table (Sta 1.5, Agi 1.2) says Str > Sta > Agi, and the 00s chapter had to be corrected after review. Rule: a stat order or weight quoted in a brief is copied from the weights doc or the profile file, never typed.
- 2 Nov 2026: the druid overlay spec said the hearth was at Sentinel Hill from chapter 05 on, from memory of the route; chapter 06 binds Lakeshire and the Alliance guide itself hearthed to Sentinel Hill afterwards without rebinding (now a check_guide check). Rule: state hearth/bind facts from the [S]/[H] tags, and let the tooling check them.
- 2 Nov 2026: the spec said "the whole Alonso remark goes" for a shield quest and an agent also deleted the Dragonslayer's Lance quest (2,550 XP) beside it. Rule: a delete instruction in a brief names the exact quest ids and lines it covers.
- 2 Nov 2026: `git add docs/` swept two untracked files Braedyn had made (docs/forever-shaman-leveling-sheet.html/.pdf) into the research-pass commit; the rule says ask before committing changes you did not make. Rule: stage by explicit file path (the files in the diff you reviewed), never by directory, and check `git status --short` for untracked files under that directory first.
- 3 Nov 2026: a subagent brief called the Repurposed Hair Band a "cloth head" item from the slot-less name in an earlier report; the DB and tooltip say cloth wrist, and the agent caught it before scoring. Rule: an item's slot, armour type or stats quoted in a brief come from the tooltip cache or qdb item row, never from the name.
- 3 Nov 2026: the sheet review found 09:62 still quoting the Strong Fishing Pole at +45 after the 2 Nov fix corrected only 02:74; the fix went to the line reported, not to every line with the value. Rule: when a quoted value is corrected, grep every chapter (and the docs/sheet) for the old value before closing the fix.
- 3 Nov 2026: weights/score_items.py still reads the 24 Sep item_tooltips.json, so scores_2026-11-03.txt carries stale stats (Rockslicer +10 Str vs tooltip +7 Str). Rule: a scores run quoted in a guide line is made from the dated tooltips file named in the run header.
