## LootOptimizer Forever - what it scores with
`Interface\AddOns\LOF\Data\StatWeights.lua` (v0.2.3, "LOF's own beta weights, no published Forever weights exist yet"). The Upgrade Advisor mixes the class's three tree rows by talent points spent (`ResolverUpgrade.lua` GetWeightMixFor); with 4/0/0 his weights are the Enhancement row unmixed:
`Str 1.0, Agi 0.6, Sta 0.3, Int 0.7, AP 0.5, SP 0.1, Dmg 0.1, Hit 11, Crit 11, Armor 0.01, melee weapon DPS 3.2` - Spirit is not listed (0). Score = sum(stat x weight); a 2H is compared with main + off-hand (off-hand DPS x 50%). There is no in-game override; the file is the only knob and an LOF update overwrites it.

Against the project weights (`docs/forever-enh-stat-weights.md`, central set with Int 1.55 after the 3 Nov Mental Dexterity change), normalised to Str = 1: Int 0.78 (LOF 0.7, close); Spirit 0.5 (LOF 0); spell damage 0.75 (LOF 0.1); weapon DPS 7 (LOF 3.2); Agi 0.3-0.43 (LOF 0.6); Sta 0 (LOF 0.3). So LOF under-rates weapons by half and ignores Spirit and spell damage, and over-rates Agi/Sta: its "upgrade" calls agree with the guide on plain Str/Int pieces and disagree on weapons, Spirit pieces, the spell-damage Totemic set and Agi/Sta leather. Not changed this round; editing the Enhancement row to `Str 1.0, Agi 0.4, Sta 0, Int 0.78, Spi 0.5, AP 0.5, SP 0.75, Dmg 0.75, Hit 11, Crit 11, Armor 0.01, DPS 7` is a one-line change in that file if he wants LOF to agree with the guide (Spirit needs a new column key; LOF reads `ITEM_MOD_SPIRIT_SHORT` already for other classes).
