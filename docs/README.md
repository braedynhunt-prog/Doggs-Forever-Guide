## 25 Sep 2026 — one shared addon: chapter split, hunter layer, Human start (DONE, untested in game; Human/Hunter lines unmaintained since 27 Oct)
- **Why one addon:** Guidelime's `[A ...]` hides a step for players who don't match (races and classes are separate lists: AND across categories, OR within — `[A Dwarf,Hunter]` = Dwarf hunter only), `[GA ...]` hides a whole chapter from the selection list, and several `[NX]` targets are offered as alternatives filtered by `[GA]`. Sage's Alliance guide is one guide for all classes built this way. So: group **"Forever Alliance 1-20"** (now "1-30"), folder `Guidelime_ForeverShaman`.
- **Chapters (11 at the time):** `00a_Northshire` `[GA Human]` 1-6 → `00b_Elwynn` `[GA Human]` 6-11 → shared; `01a_ColdridgeValley` `[GA Dwarf]` 1-6 → `01b_DunMorogh` `[GA Dwarf]` 6-11 → shared; shared `02_LochModan` 11-15 → `03_HallOfThanes` 15-16 → `04_LochModan2` 16-17 → `05_Westfall` 17-18 → `06_Redridge` 18-19 → `07_Deadmines` 19-20 → (08 onward: see `20-30-build.md`). The starter chapter was split because Guidelime stores manual ticks by step index per chapter and wipes them when a chapter's step count changes (quest/XP steps and `[G]`s on quest lines re-derive from the server; standalone goto/text/`[T]`/`[V]`/`[H]`/`[F]` lines don't; `/lime skip` skips the active block). Rules going forward: coords on quest lines, notes as `[O]`/`[OC]` so they never hold the cursor, and if a mid-chapter edit keeps the step count, add/remove a line so it resets cleanly instead of misaligning. Loch Modan 11-15 could still be split at 13.
- **Hunter layer (73 `[A Hunter]` lines)** and the **Human route (00a/00b)**: left in the files, unmaintained. Details of what they contain were in the claude.ai Project README if ever needed.
- **Verification (25 Sep):** a subagent audit of 00a/00b (every line) and all tagged lines in 01a-08 against Questie + the atlas found and we fixed: Rare Books hands in to Brother Paxton not Dughan; the Stonefield/Maclure chain NPCs were swapped; A Fishy Peril / Further Concerns need level 7; Red Linen Bandanas come from Defias Rogue Wizards at Stone Cairn and Defias Bandits at Brackwell; gnoll camps are north of Stone Cairn Lake (67.5,42); Rogue Wizards at 74,52; Mangy Wolf not Young Wolf south of Goldshire; Brog Hamfist sells no food; Princess's adds are boars; Bundles of Wood are north of Eastvale along the river; Westfall DOES sell shot (Quartermaster Lewis) and so does Lindsay Ashlock in Lakeshire. Everything else — all 102 `[TAR]` ids, all quest ids/titles, givers, prerequisites, race/class masks, item stats, vendor claims — checked out.
- **Chain bug fixed the same day:** `07_Deadmines.lua` had `[NX 20+ Loose Ends]`, which Guidelime turned into the key `20- + Loose Ends`; it never matched `[N 20-22 Loose Ends]`. Now the checker verifies every `[NX]` against the `[N]` names.
- **Tooling:** `check_guide.py`, `loc.py`, `pool.py`, `qdetail.py` resolve paths relative to the Atlas folder (env `FOREVER_ATLAS` overrides); the Questie DB is `tooling\qdb\{quest,npc,object,item}.json` (since 17 Oct the decoded Forever DB; the Classic one is `qdb_classic\`); the checker knows the 00a/00b/01a/01b level bands, accepts `[A Hunter]`, checks `[NX]` links, and is race-aware for duplicate pickups. `weights\hunter_score.py` scores every route item for a hunter. `python tooling\check_guide.py` runs on the PC.

## Why this route and not Sage's
Alliance-usable quest XP available at level ≤ 20, from the atlas + Questie (non-class, non-seasonal): Dun Morogh 35.6k (16.8k of it new, plus 3.4k shaman), Loch Modan 44.2k (6.9k new), Ironforge 18.6k (7.3k new incl. Hall of Thanes), Westfall 40.6k (10.7k new), Redridge 29.7k (4.3k new), Deadmines 9.2k, Elwynn 38.9k (17.4k new), Stormwind 36.5k (19.2k new), Darkshore 73.2k (6.7k new), Teldrassil 34.5k (8.4k new). Level 20 needs 159.1k XP total. The Eastern Kingdoms loop (DM + LM + IF/HoT + WF + RR + DM) holds ~180k of quest XP without touching Kalimdor, and the new content is concentrated exactly there (Dun Morogh got the most new quests of any zone). Darkshore is huge but has almost nothing new and costs two boats.

**Sage's Forever release (Sage-2026.09.24.zip, v2.5.6)**: the 1-20 zone files contain zero new Forever quests; its Hall of Thanes file is the only place Forever quest IDs appear (same as ours). Sage's route is a speedrunner's: Dun Morogh 1-11 → Loch Modan 11-13 → deliberately die to graveyard-teleport to Menethil → boat → Darkshore 11-19 → Redridge 19-20 → Duskwood 20-23. It skips Hall of Thanes, Deadmines and every group quest. Where our chapter 1 overlaps Sage's Dun Morogh the order is nearly identical; ours inserts Archaic Rune + Call of Earth (4), Eric Brighthammer's camp (Great Outdoors, Camping 101), Secure the Mountain, Flintfire's Shipment, Frosthowl, Father Gavin (4 quests, 2,870 XP), Never Saddle on Quality, Stolen Blasting Powder, the Earthseer Farsen chain into Hall of Thanes, Call of Fire (10). Net: ~10k more quest XP in Dun Morogh than Sage, so chapter 1 ends at 11-12 instead of 11.

## How it was built (so it can be re-done for 30-40)
- Data: atlas `data/quests.json` + `entities.json` + `zone_*.json` (Sep 23 scrape — **Wowhead now blocks the scraper**), the Questie DB as `tooling/qdb/*.json` (Forever since 17 Oct, decoded by `questiedb_baked.py`; Classic in `qdb_classic/`), `pool.py <zoneId>` prints a merged per-zone quest pool (new/updated/unchanged, givers + coords, prereqs, rewards), `qdetail.py <questIds>` dumps objectives with entity coords + comments + item stats for new quests, `loc.py "<npc name>"` prints Questie spawn centroids, `check_guide.py` runs the static flow check (tag syntax, zone names, QA→QT/QS, prerequisites per race chain, level bands, `[NX]` chain, race-aware duplicates), `tugs_diff.py` diffs a TUGs Guidelime folder against ours. All scripts are in `tooling\` with a README on the paths they expect. Subagent verification passes against the same data caught wrong givers, coordinate misses, NPC roles and level requirements — re-run one after any large edit.
- Wowhead item stats for new items: the tooltip endpoint (`nether.wowhead.com/forever/tooltip/item/<id>`, reachable from a shell with a browser User-Agent) still works; the item search page and NPC pages do not (CloudFront 403 / challenge page since October). Item ids come from `tooling\qdb\item.json`.
- Guidelime on Forever: CurseForge Guidelime has shipped a Forever flavor since v6.000 (24 Sep); v6.008 (15 Oct) reads the official QuestieDB. The parser accepts `[QA id title]` — the title is what displays when the DB doesn't know the quest.
- Guidelime applies-to mechanics (verified in the wiki + source, 25 Sep): `[A ...]` on a step hides the line for non-matching faction/race/class (race and class lists are ANDed); `[GA ...]` does the same for a whole chapter in the selection list; several `[NX]` in one chapter are offered as alternatives filtered by `[GA]`.
- Map coordinates: Forever's Stormwind and Redridge maps differ from Classic's (transform in `tooling\coord_transform_forever.json`); the Forever NPC/object spawns in `qdb\` are already in Forever map space, Questie Classic spawns and old Wowhead-Classic numbers are not.
