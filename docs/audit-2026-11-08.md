## What the sheet settled
1. **Mana regen = 1.25 x Spirit per 5 s, nothing else.** 41 x 1.25 = 51.25. No Int term (the swap changed nothing) and no base term. Vanilla's shaman formula (17 + Spi/5 per 2 s tick), which the model used, would read 63. The slope is 0.25 mana/s per Spirit, 2.5x the model's 0.1. Open: a level term (re-read at the same Spirit at 25 or 30).
2. **Crit tables and base crit.** Melee 9.6% = 0.46 base + 39 / 9.4 (foreverdb L21) + 5% Thundering Strikes; spell 9.55% = 2.3 base + 45 / 20.0 + 5%. So foreverdb's client tables hold to the decimal, base melee crit is 0.46 (the model had 1.7), base spell crit 2.3 as assumed, and Thundering Strikes gives 1% per rank to both melee and spells (as modelled). The model's Agi table was 10-15% too generous below 25 (6.2 / 7.5 / 8.6 at 10 / 15 / 20 vs 7.3 / 8.2 / 9.4).
3. **Earth Shock.** The model held the beta's 49 for rank 3; the 3 Nov build raised it to 69-74 and the tooltip reads 71-76 at 21 (within-rank level scaling, realPointsPerLevel 0.9). Every rank is now about Classic. Lightning Shield on the same build: 13 / 24 / 40 / 64 per orb (Classic 13 / 29 / 51 / 80; the model had a flat 10% cut). Healing Wave ranks 3-5 heal 1.73-1.78 HP per mana (model 1.8 -> 1.75).
